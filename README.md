# 🚀 Machine Learning Project Suite

This repository showcases a collection of machine learning projects built using **Python**, integrated with modern frontend and backend technologies like **Angular** and **.NET**. Each project demonstrates real-world applications of ML models with interactive UIs and robust APIs.

## 🛠️ Tech Stack

- **Frontend:** Angular  
- **Backend:** ASP.NET Core  
- **Machine Learning:** Python (Flask / FastAPI / TensorFlow / Scikit-learn)

## 📦 What's Included

- Real-time prediction tools
- ML model deployment and integration
- REST API communication between Python and .NET
- User-friendly Angular interfaces
- Projects like image classification, regression models, and more

## 📁 Project Structure

Each project is organized into modules containing:

- ✅ Model training and evaluation scripts (Python)
- ✅ Web API integration (ASP.NET Core)
- ✅ Frontend implementation (Angular)
